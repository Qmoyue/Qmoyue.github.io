# 测试职责

测试保护读者的实际操作和内容契约。页面验证使用仓库真实内容和 Astro 静态构建；单元与组件测试只覆盖难以在现有页面触发的输入边界或生命周期。假时钟仅控制动画调度，不伪造页面与外部依赖。

## 命令

- `pnpm run validate`：Prettier、Oxlint、Astro 类型检查、Vitest。
- `pnpm run build`：严格内容检查后构建静态站点。
- `pnpm run test:e2e`：先构建，再用 Chromium 验证实际页面；CI 已构建时设置 `PLAYWRIGHT_USE_BUILT_SITE=1`。
- `pnpm run verify`：依赖审计、validate、test:e2e。
- `pnpm run capture:visual [文件名]`：按需采集桌面、移动、普通/减少动效截图。它是人工复看工具，不计入 CI 回归测试。

Playwright 通过 `scripts/preview-test-site.mjs` 调用 Astro 的 preview API，自行管理前台测试服务器及关闭流程。它不占用 Astro CLI 的交互预览锁；端口已被使用时直接报错，不切换端口或测试其他正在运行的站点。

## 保留的能力边界

| 测试组                                                                     | 保护内容                                                                        | 选择该边界的原因                                             |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `tests/contracts/content-contract`                                         | 元数据、日期、Markdown、资源与链接错误显式报错                                  | 使用真实文章及针对单个契约的非法输入；错误进入构建前即可定位 |
| `tests/unit/{blog-covers,post-search,navigation}`                          | 封面选择/缺失、正文搜索/代码排除、路由路径边界                                  | 纯输入输出，快速验证易错边界                                 |
| `tests/unit/{home-model,home-opening}`                                     | 群岛数据可序列化、必需内容、播放完成/取消/减少动效                              | 真实首页数据；取消后无后续更新，不固定内部毫秒时序           |
| `tests/component/{article-toc,friends-carousel,project-card,sakura-field}` | 无标题目录、单友链/空列表、本地项目链接、非法花瓣数量                           | 现有页面无法覆盖的独立组件分支                               |
| `tests/e2e/{home,navigation}`                                              | 首屏播放、头像重触发、两屏切换/拖拽、掉落清理、时区、触摸/键盘/无 JS 导航       | 真实浏览器状态、布局和副作用；单位测试不能替代               |
| `tests/e2e/{archive,article-code,article-navigation}`                      | Enter 搜索、空态恢复、高度变化后的进度、无 JS 阅读、代码/表格键盘滚动、目录定位 | 真实文章与实际滚动，避免只验证 tabindex 或静态 DOM           |
| `tests/e2e/{friends,sakura,site-pages}`                                    | 轮播、外链安全、屏幕内布局、减少动效、真实资料/项目/页脚                        | 使用发布数据，覆盖 SSR 与水合后的结果                        |
| `tests/e2e/{seo,accessibility}`                                            | canonical、RSS、sitemap、404 和 WCAG axe 检查                                   | 静态发布契约与可访问性边界                                   |

## 精简依据

删除的首页组件 SSR、页脚组件和技术栈空态测试，由无 JS 首页与实际资料/页脚 E2E 接替；外部项目链接由真实项目 E2E 验证。目录链接与花瓣数量不再同时做组件和浏览器两份断言。已移除的主题/配置工厂不保留测试，实际配置由导入校验、构建、导航与 SEO 测试保护。

原 `visual-smoke` 中的有效行为归入首页、归档和资料测试；掉落词自然清理合并到同一次退出/重返流程。删除固定封面去重数量、旧元素不存在、旧文案不存在等没有独立契约的断言。封面加载保留在归档真实流程中。

滚动回归还覆盖真实短页面的零滚动范围，以及首页切屏中被原生 Home 键中断的状态恢复。操作 `client:idle` 群岛前等待水合，避免把没有事件处理器的静态按钮误当作验证通过。归档搜索用已发布文章末尾的关键词验证完整索引；正文与字数契约覆盖反引号、波浪线围栏和缩进代码，资源契约同时检查内联与引用语法。

当前技术栈没有发布条目，删除了虚构条目的展示测试，接受非空分支暂时没有自动覆盖；发布真实条目时应补充对应浏览器断言。截图采集没有自动像素基线，视觉修改仍需复看桌面、移动与动效画面。测试通过不等同于所有页面都经过完整 WCAG 人工审查。
